## Commands Practiced

```bash
nmap -sV <target-ip>
sudo nmap -sS <target-ip>
sudo nmap -sU <target-ip>
nmap -O <target-ip>
nmap -A <target-ip>
nmap -p- <target-ip>
```

To understand network scanning and enumeration techniques using Nmap in an authorized lab environment.
